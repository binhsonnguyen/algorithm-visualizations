Bubble Sort

Pseudocode

BUBBLE_SORT(a, n):
    for i ← 0 to n - 2 do
        swapped ← false
        for j ← 0 to n - 2 - i do
            if a[j] > a[j + 1] then
                swap a[j] ↔ a[j + 1] ; swapped ← true
        if swapped = false then return a
    return a
